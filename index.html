Timing

Connect to sample the report stream.
Measured on one unit over USB: in the default latency mode the controller sent a report every 16 ms (62 Hz). After Option + 4K (lowest latency) it sends every 4 ms (247 Hz), the fastest its USB setup allows. If this box ever shows SLOW again, the mode was reset.
