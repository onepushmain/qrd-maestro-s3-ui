SOCD output
Neutral
The controller cleans opposite directions before the PC sees them, so the SOCD box shows the result. Hold Left + Right: neutral in SOCD1, SOCD2 and EZ. Hold Up + Down: Up in SOCD1 and EZ, neutral in SOCD2. Newer firmware adds SOCD3, where the last input wins. The page sees only what the controller sends, not what you hold.

A bounce is a change that follows the previous one within 12 ms, the sign of a switch double-firing. Mash each button about 20 times. A red row is a switch worth hot-swapping.

Timing

Connect to sample the report stream.
On the unit this was built with, the default latency mode sent a report every 16 ms (62 Hz) and the fastest mode every 4 ms (about 250 Hz, the most the USB polling allows). Over Bluetooth the rate is lower and less steady, which is one reason to use the cable for matches.

Controller shortcuts

Option + Up (2 s)Cycle SOCD: SOCD1 → SOCD2 → EZ. Newer firmware adds SOCD3 (last input wins). Option + 4KLatency: the fastest setting. Called "lowest" in the firmware 1.05 notes and "highest" in the printed manual. Option + 2KLatency: automatic. Option + 4PLatency: medium. Option + 3K or 3PThe other latency settings. The manual and the 1.05 notes disagree on which is which, so watch the report rate after pressing. L3 + R3 (2 s)Button backlights: cycle the 8 colours, breathing and colour-changing patterns, and off. Option + Left / Down / Right (2 s)Direction buttons act as D-pad / left stick / right stick. Turbo + button (2 s)Give that button turbo. Hold Turbo 2 s to switch between continuous and infinite. Option + Share (3 s)X-Input mode, wired only. The dashboard cannot see the controller in this mode. Home + Share, while offBluetooth pairing. Pick "Wireless Controller" on the host.
In PlayStation names: 2K is ○, 3P is L1, 4P is R1, 3K is L2 and 4K is R2. From QRD's printed manual and firmware 1.05 notes. The manual says the SOCD, direction, latency and turbo settings are saved on the controller.
